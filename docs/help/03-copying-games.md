# Copying games to RetroArch

## The cart

Games you want to copy go in the cart first. Press **+Add** on a game
card. The bar at the bottom of the library shows how many games are in
the cart. When you are viewing a featured category, the bar also
offers **Add all** for every game in it.

## Preview, then copy

1. Press **Dry-run** in the cart bar. It shows what would be copied
   and writes nothing.
2. Check the list, then press **Copy**.

A window shows progress while the files copy.

## What gets copied

- The ROM for each game in the cart.
- Any BIOS a game needs to run.
- A RetroArch playlist (`mame.lpl`), so the games show their full
  names in RetroArch without renaming any files.

Your source ROM folder is never changed. If a copy replaces a file in
the destination, the old file goes to a recycle bin rather than being
deleted.

## Checking what happened

The **Activity** page lists past copies.
